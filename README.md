# IGEV_SC — Sitio web

Pequeña landing original convertida a sitio informativo para el Instituto Gastronómico Venezuela (IGEV_SC).

Archivos añadidos:

- THEME.md — paleta de colores y guía de tipografías.
- ABOUT.md — información institucional.
- COURSES.md — listado y descripciones de cursos.
- INSTRUCTORS.md — perfiles docentes.
- CONTACT.md — datos y formulario de contacto sugerido.
- FAQ.md — preguntas frecuentes.
- GALLERY.md — guía y estructura para galería de imágenes.
- SYLLABI.md — vínculos y estructura de sílabos.
- EVENTS.md — calendario y talleres.

Próximos pasos sugeridos:

1. Convertir las páginas Markdown a plantillas HTML o a un generador de sitios (Jekyll, Eleventy, Hugo) si quieres mantenimiento más fácil.
2. Implementar formularios funcionales (Formspree, Netlify Forms o backend propio) para inscripciones.
3. Añadir páginas internas (detalle de curso, ficha de instructor) y navegación multi-página.
4. Revisar y añadir assets que faltan (sílabos en PDF, fotos para galería).

Si quieres, puedo generar las páginas HTML correspondientes y una navegación básica manteniendo los colores y tipografías actuales.
