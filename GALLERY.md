# Galería — IGEV_SC

Imágenes representativas de clases, platillos y eventos.

Sugerencia de estructura de assets para galería:
- `assets/images/galeria/clase1.jpg`
- `assets/images/galeria/plato1.jpg`
- `assets/images/galeria/evento1.jpg`

Incluye leyendas cortas para cada imagen y créditos a fotógrafos cuando apliquen.

Ejemplo de uso en HTML:

```html
<figure>
  <img src="assets/images/galeria/plato1.jpg" alt="Plato ejemplo">
  <figcaption>Clase de Repostería: tartas artesanales</figcaption>
</figure>
```
